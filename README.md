React Note App

React Note App is a learning project built with React to practice component-based architecture, state management, and form handling. The app allows users to create, edit, and delete notes with ease.

👉 View Live App

🛠️ Technologies Used

React — A JavaScript library for building user interfaces

Vite — A fast build tool with hot module replacement

CSS — Styling components

React Router — Client-side routing

⚙️ Features

Create new notes with a title and content

Edit existing notes

Delete notes

Responsive design for mobile and desktop
