
# React Note App

**React Note App** is a personal learning project built with React to practice component-based development, state management, and form handling. The app allows users to create, edit, and delete notes with a clean and simple interface.

## 🔗 Live Demo 
👉 [View Website](https://05-notehub-xi-five.vercel.app/)

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **React**
- **Vercel (Deployment)**

## 📌 Features

- Add, edit, and delete notes 
- Search notes by content  
- Clean and maintainable React codebase

## 👩‍💻 My Role

This was a learning project where I focused on practicing React by implementing core features like creating, editing, deleting, and searching notes.
